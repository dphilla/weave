What actually moves?

The woven Wasm module captures its live call stack and locals into linear memory. Weave transfers memory pages, control globals, and the progress service’s state, then verifies and commits the handoff. The destination resumes the suspended entry; it does not start a new π calculation.

Digits are ordinary floating-point estimates from a Kahan-compensated series, not an arbitrary-precision π record. Progress and error are real observations; the chart and motion are explanatory visualization.

A small, honest lab.

Six tabs are six independent execution environments—not six separate computers. The default tab transport is entirely local; optional WebRTC exercises the network transport and depends on working local ICE connectivity. Both use the unchanged Weave migration engine. No STUN, TURN, account, or backend is configured. Background tabs can be throttled or discarded. If an owning tab disappears, the demo stops guessing: it will not silently restart the workload.
